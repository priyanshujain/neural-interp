# neural-interp

Neuron-level monosemanticity from exact input decompositions. Each strong activation of a unit is described by the exact per-input contributions that produced it, and those descriptions are clustered into modes, so every activation gets one meaning at runtime.

The first target is an independent reproduction of the InceptionV1 `mixed4e:55` result.
